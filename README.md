1. Name of my project - Keen Keeper

2. A short description 
Keen Keeper is a friendship and communication management web application where users can track and organize their interactions such as calls, text messages, and video calls. The application provides timeline-based interaction history along with analytics and filtering features for better relationship management.

3. Technologies you used
-React.js
-JavaScript (ES6)
-Tailwind CSS
-React Router
-Context API
-Recharts
-DaisyUI

5. key features of your project
a. Timeline-based interaction tracking
b. Filter interactions by call, text, and video
c. Friendship analytics with Pie Chart visualization
d .Responsive and modern UI design
e .Dynamic data rendering using Context API
f. Real-time interaction statistics
